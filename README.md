# LogiRisk AI — Delivery Risk Intelligence

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Open%20App-brightgreen?style=for-the-badge)](https://logirisk-ai.streamlit.app/)

🚀 **Live App:** https://logirisk-ai.streamlit.app/

An experimental machine learning application that estimates late-delivery risk from historical e-commerce order features.

## Features
- **Risk Studio:** Analyze an individual order.
- **Batch Analytics:** Score multiple orders and export prediction results.
- **Live Simulator:** Generate synthetic demo orders and monitor model outputs.
- **Model Lab:** Explore model information and experimental metrics.

## Tech Stack
Python · Streamlit · Pandas · NumPy · Scikit-learn · XGBoost

## Disclaimer
This is an academic research prototype based on historical data. Model scores are not verified or calibrated real-world probabilities and do not guarantee delivery outcomes. The Live Simulator uses synthetic demo orders, not a live commerce integration.
